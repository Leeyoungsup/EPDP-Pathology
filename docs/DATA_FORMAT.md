# EPDP — Dataset Format

This repository ships **no images and no model checkpoints**. To run any of the
training scripts you must arrange your own histopathology patches into the
folder layouts described below.

The original NIA dataset that the manuscript was trained on is restricted-access
medical data and cannot be redistributed; any equivalently structured dataset
of class-labeled patches works.

---

## 1. Class-conditional diffusion (`scripts/train_diffusion_*.py`)

A single root directory whose immediate children are the **subtype class
folders**. Each class folder holds image patches of that subtype.

```text
<data_root>/
├── BRNT/
│   ├── 0000.png
│   ├── 0001.png
│   └── ...
├── BRLC/
├── BRDC/
├── BRIL/
└── BRID/
```

| Item | Specification |
| --- | --- |
| Class folder names | Must exactly match `class_list` in the YAML (case-sensitive) |
| Image format | PNG / JPEG / TIFF — anything `PIL.Image.open` can read |
| Channels | RGB (single-channel images are auto-converted) |
| Patch size on disk | Any size; loader will resize to `image_size` (default 1024) |
| Magnification | 40× WSI patches in the manuscript (informational) |
| Patches per class | Any count; the loader samples uniformly within the class |

Class lists from the manuscript:

| Organ | YAML | Class folders |
| --- | --- | --- |
| Breast | `configs/diffusion_breast.yaml` | `BRNT`, `BRLC`, `BRDC`, `BRIL`, `BRID` |
| Stomach | `configs/diffusion_stomach.yaml` | `STNT`, `STIN`, `STDI`, `STMX` |

Point the script at this root with `--data-root`:

```bash
python scripts/train_diffusion_breast.py \
    --config configs/diffusion_breast.yaml \
    --data-root /path/to/breast_patches \
    --output-dir runs/diffusion_breast
```

## 2. CycleGAN stain normalization (`scripts/train_cyclegan.py`)

Two **unpaired** image pools — Dataset A (source domain) and Dataset B (target
/reference domain). No subfolders are required inside each pool.

```text
<cyclegan_root>/
├── trainA/         # source domain (e.g. raw scans)
│   ├── *.png
└── trainB/         # target domain (reference stain)
    └── *.png
```

| Item | Specification |
| --- | --- |
| Pairing | Unpaired (A and B can have completely different counts) |
| Image format | PNG / JPEG / TIFF |
| Channels | RGB |
| Patch size on disk | Any; resized/cropped to `crop_size` (default 1024) |

Run:

```bash
python scripts/train_cyclegan.py \
    --config configs/cyclegan.yaml \
    --data-root /path/to/cyclegan_root \
    --output-dir runs/cyclegan
```

## 3. EfficientNetV2-L subtype classifier (`scripts/train_classifier.py`)

Same class-folder layout as the diffusion data, plus an explicit choice of
**organ** (the script reads the matching `*_classes` field from the YAML).

```text
<classifier_root>/
├── BRNT/
├── BRLC/
├── BRDC/
├── BRIL/
└── BRID/
```

For the **EffNet-Real** classifier point `--data-root` at the real patches.
For **EffNet-Syn** point it at the synthetic patches generated by the diffusion
scripts (the per-class subfolders under `runs/diffusion_breast/samples/`).

Run:

```bash
python scripts/train_classifier.py \
    --config configs/classifier.yaml \
    --organ breast \
    --data-root /path/to/classifier_root \
    --output-dir runs/classifier_real_breast
```

## 4. Where outputs go

All training scripts write **only inside** `--output-dir`:

```text
<output_dir>/
├── checkpoints/
│   └── ckpt_<epoch>.pt
├── samples/                # diffusion only — DDIM samples per epoch
│   └── BRNT/0001.png
├── log.csv                 # epoch, loss, lr
└── config.snapshot.yaml    # the YAML used for this run
```

No file is ever written outside `--output-dir`, so the repo stays clean.
